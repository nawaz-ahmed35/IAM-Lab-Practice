## Add User to Security Group in Azure AD (Entra ID)

### Objective
To add an existing user to a security group in Microsoft Entra ID for access management.

### Steps Performed
1. Logged into Azure Portal
2. Navigated to Microsoft Entra ID
3. Selected Groups
4. Chose the required Security Group
5. Clicked on Members → Add Members
6. Searched and selected the user
7. Clicked on Select to add the user

### Result
User was successfully added to the security group and inherited the assigned permissions.

### Note
Adding users to a security group helps manage access efficiently without assigning permissions individually.
