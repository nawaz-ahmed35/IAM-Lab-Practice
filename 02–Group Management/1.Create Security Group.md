## Create Security Group in Azure AD (Entra ID)

### Objective
To create a security group in Microsoft Entra ID and manage user access through group membership.

### Steps Performed
1. Logged into Azure Portal
2. Navigated to Microsoft Entra ID
3. Selected Groups → New Group
4. Chose Group type as "Security"
5. Entered Group name and description
6. Added members to the group
7. Clicked on Create

### Result
Security group was successfully created and users were added for centralized access management.

### Note
Security groups are used to assign permissions to multiple users at once instead of assigning access individually.
