## Remove User from Security Group in Azure AD (Entra ID)

### Objective
To remove an existing user from a security group in Microsoft Entra ID to revoke access.

### Steps Performed
1. Logged into Azure Portal
2. Navigated to Microsoft Entra ID
3. Selected Groups
4. Chose the required Security Group
5. Clicked on Members
6. Selected the user to be removed
7. Clicked on Remove

### Result
User was successfully removed from the security group and access permissions were revoked.

### Note
Removing a user from a security group will immediately remove all access that was assigned through that group.
