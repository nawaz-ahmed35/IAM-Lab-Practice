## Create User in Azure AD (Entra ID)

### Objective
To Enable a user account in Microsoft Entra ID.

### Steps Performed
1. Logged into Azure Portal
2. Navigated to Microsoft Entra ID
3. Selected Users → Click edit
4. Click the Enable account
6. Verified user creation

### Result
User account successfully Enabled.
