## Reset Password in Azure AD (Entra ID)

### Objective
To reset the password for an existing user account in Microsoft Entra ID.

### Steps Performed
1. Logged into Azure Portal
2. Navigated to Microsoft Entra ID
3. Selected Users
4. Searched and selected the required user
5. Clicked on "Reset Password"
6. Generated new password and shared with the user

### Result
User password was successfully reset and user was able to log in with the new credentials.
