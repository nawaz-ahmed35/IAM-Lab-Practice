## Disable User in Azure AD (Entra ID)

### Objective
To Disable a user account in Microsoft Entra ID.

### Steps Performed
1. Logged into Azure Portal
2. Navigated to Microsoft Entra ID
3. Selected Users → Click Edit
4. Click Edit Account Status
5. Select the Disable account and Cleck Save
6. Verified user Disable.

### Result
User account successfully created.
