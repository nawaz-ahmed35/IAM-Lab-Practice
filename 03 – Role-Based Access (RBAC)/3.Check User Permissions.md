## Check User Permissions in Azure AD (Entra ID)

### Objective
To verify the roles and permissions assigned to a user in Microsoft Entra ID.

### Steps Performed
1. Logged into Azure Portal
2. Navigated to Microsoft Entra ID
3. Selected Users
4. Searched and selected the required user
5. Opened Assigned Roles section
6. Reviewed roles and permissions assigned to the user

### Result
User roles and permissions were successfully verified.

### Note
Regularly checking user permissions helps ensure proper access control and prevents unauthorized access.

### Use Case
Used during audits or troubleshooting to verify whether a user has the correct access or permissions.
