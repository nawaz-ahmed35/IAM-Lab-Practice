## Assign Role to User in Azure AD (Entra ID)

### Objective
To assign an administrative role to a user in Microsoft Entra ID to grant specific permissions.

### Steps Performed
1. Logged into Azure Portal
2. Navigated to Microsoft Entra ID
3. Selected Roles and Administrators
4. Chose the required role (e.g., User Administrator)
5. Clicked on Add Assignments
6. Selected the user
7. Clicked on Add to assign the role

### Result
Role was successfully assigned to the user, and the user gained the corresponding permissions.

### Note
Roles should be assigned based on the principle of least privilege to ensure security.

### Use Case
Used to grant specific administrative permissions such as managing users, resetting passwords, or handling access without giving full admin rights.
