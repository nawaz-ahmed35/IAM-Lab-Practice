## Remove Role from User in Azure AD (Entra ID)

### Objective
To remove an assigned administrative role from a user in Microsoft Entra ID to revoke elevated permissions.

### Steps Performed
1. Logged into Azure Portal
2. Navigated to Microsoft Entra ID
3. Selected Roles and Administrators
4. Chose the assigned role (e.g., User Administrator)
5. Clicked on Assignments
6. Selected the user
7. Clicked on Remove

### Result
Role was successfully removed from the user, and the user no longer has the associated permissions.

### Note
Removing unnecessary roles helps maintain security by following the principle of least privilege.
